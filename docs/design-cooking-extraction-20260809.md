# Design: 협동 추출 요리 게임 (가제 미정)

Generated by /office-hours on 2026-08-09
Mode: Startup
Status: DRAFT
Supersedes: v1 소리는 빛이다 (2026-08-05)
Carried forward: 코어 교체. "소리는 빛" 단일 법칙 게임 → 추출×요리 루프. 음파 메카닉은 폐기가 아니라 강등 — 스테이지 기믹 또는 정전 귀환 이동 방식으로 재배치. 판정 필터·검증 원칙·"즉사 금지"는 그대로 승계.

## 한 줄 컨셉

동물이 주인인 장소에서 재료를 훔쳐다, 푸드트럭에서 요리해 파는 1~4인 협동 추출 게임.

## Problem Statement

리썰컴퍼니·R.E.P.O.·Content Warning을 소진한 친구 그룹에게 팔 수 있는, 설명 없이 3초에 읽히는 새 프레임. 수요 증거는 여전히 0이고, 첫 검증 대상은 개발자의 실제 친구들이다.

## 코어 루프

정차, 오늘의 주문서 수령 (쿼터는 **매일** 갱신 — 리썰의 마감 시계 직역) → 주문에서 목적지 도출 (레시피가 미션 생성기: 계란이 필요하면 양계장, 꿀이 필요하면 벌집) → 원정: 침입 · 회수 · 탈출 (재료의 주인 = 동물 = 위협) → 귀환 (정전 구간이면 음파 이동 기믹) → 다운타임 요리 (원정과 같은 동사) → 납품 · 구매 (프라이팬 = 2계란) → 다음 정차지로 이동.

## 판정 필터 — 모든 결정의 기준 (승계)

클립 가독성(무음 3초에 파악) / 실패가 구경거리 / 몸의 행위가 화면에 보임 / 적 없음 또는 적음 / 한 줄 컨셉 / 행위 의도의 애매함("쟤 지금 일부러 그런 거 아냐").

## 핵심 결정 — 이 세션에서 확정

1. **뼈대는 빌리고 정체성은 새로 단다.** 리썰의 검증 구조(원정 → 쿼터 → 반복)를 그대로 쓴다. 검증된 뼈대 + 새 메타는 Content Warning이 상업적으로 증명한 수법이고, 솔로 스코프에서 이길 확률이 가장 높은 조합. 정체성은 요리와 동물에서 나온다.
2. **쿼터는 무게가 아니라 매일의 주문(레시피)이다.** "몇 키로"제는 최저가 재료 반복 채집이 정답이 되어 요리가 장식으로 전락한다. 매일 갱신되는 주문제("오늘 오믈렛 3, 꿀버터 1")는 목적지 선택에 자동으로 의미를 부여한다. 주문 N개 중 M개 선택으로 자유도 확보.
3. **왜-질문이 공짜인 설정.** 왜 가나 — 재료가 거기 있으니까. 왜 적대적인가 — 걔네 거니까. 왜 싸우나 — 훔쳤으니까. 몬스터가 아니라 동물이라 개연성 요구와 맞고, "복수하는 닭 떼"는 젤다 꼬꼬 밈이 수십 년째 증명한 코미디 계보다. ← Round 2
4. **요리는 두 번째 게임이 아니다.** 오버쿡드식 스테이션·미니게임 금지. 동사는 원정과 동일 — 물리로 잡고 나르기. 계란을 팬에 떨어뜨리고, 팬을 불에 올리고, 완성물을 창구에 올린다. 신규 시스템은 **열원 위 상태 변화(날것 → 익음 → 탄 것)** 단 하나.
5. **재료 1개 = 용도 3개 경제.** 먹으면 버프 / 모으면 장비·스탯(예시: 프라이팬 = 2계란) / 넘기면 주문 마감. 리썰 고철은 팔 줄만 아는 단일 용도 — 귀환할 때마다 소비 vs 투자 선택이 생기는 게 차별점. 프라이팬은 스탯 숫자가 아니라 주방에 실물로 걸리고, 닭을 쫓는 물리 도구로도 쓸 수 있다. 단, 3용도로 찢긴다는 **구조**가 확정이고, 교환의 화폐 단위(생재료 vs 요리)와 전투 허용 범위는 미해결 질문 참조. ← Round 2
6. **압박은 납품 마감 하나.** 요리는 원정 사이 다운타임 — 손이 바쁜 사교 공간(리썰 궤도선의 상위호환). 친구가 내 팬을 "실수로" 치는 순간, 의도 모호성 필터가 주방까지 들어온다.
7. **음파 자산은 재활용.** "소리는 빛이다" 2D/3D 프로토(평면 로직 + 3D 렌더 구조, 1인칭 컨트롤, 파동 셰이더)는 정전 귀환 기믹 또는 어둠 스테이지에 이식.

## 실패 = 클립

계란은 깨진다(전력질주가 리스크가 됨 — R.E.P.O.의 "비싸고 약한 짐 운반"이 공짜로 들어옴) / 요리는 탄다(연기) / 닭 떼 추격전(무음 3초 가독) / 잡혀도 즉사 금지 승계 — 동물이니 더더욱: 재료 강탈·쫓겨남 계열로 (미결).

## 폐기·경유 목록 (다시 제안하지 말 것) ← Round 1

1. **단순 길찾기 탈출** — 출구 도달이 목표인 구조. 한 번 풀면 끝나는 퍼즐이라 맵 외우는 순간 죽음. 기각.
2. **회수 경제 단독안** ("소리 나는 물건 들고 복귀") — 경제 구조만 있고 동사가 없다는 지적으로 기각. "좀더 명확하게 뭘해야하는지 핵심적인 게임요소가 있었으면해"가 기각 사유 원문.
3. **감지기 종 사냥 + 붕괴 광산 조난 프레임** — "소리로 유인해 종 밑에서 울려 잡기" + 광부 조난 신호 설정. 인과는 성립했으나 개발자가 추출×요리 컨셉으로 방향을 확정하며 대체됨. 단, "구조 신호 = 위험 신호" 아이디어는 정전 귀환 기믹에 재활용 여지 있음.

## 겹침 지도 — 정직 버전

- 뼈대: Lethal Company / R.E.P.O. / Content Warning / Backrooms 계열(Escape the Backrooms 등 — "들어가서 피해서 나온다"의 다른 축) — 구조 차용, 메타 교체
- 채집→요리: Dave the Diver (솔로 어드벤처)
- 협동 요리: Overcooked / PlateUp! (요리가 코어)
- 물리 요리: Cooking Simulator (솔로)
- 빈 칸 가설: **추출 원정 + 물리 요리 기지 + 협동 + 재료 주인이 적** 이 네 개가 한 칸에 모인 게임 — 미검증. 스팀 직접 스캔 필요 (경험상 개발자 본인 조사가 더 정확했음: Perception·Devil's Tuning Fork·Scanner Sombre 전례).

## 스코프 가드레일 — 솔로 개발

- 신규 시스템 1개 원칙 (지금은 열 상태변화)
- 인원 1~4, 솔로런 성립 필수(리썰 선례), 인원 게이트 금지 (승계)
- 보류함: 영업 중 재료 소진 러시 / 부패·허기 시계 / 신선도 보너스 / 이전 동사 후보(벌목·게잡이·빙판 건너기)의 병합 또는 대체

## 기술 로드맵

**1차 — HTML/JS 웹 프로토 (링크 배포, 친구 검증)**
검증 질문: "잡고 나르기 + 깨짐 + 동물 반응"이 조작만으로 웃긴가?
범위: 양계장 수직절단 — 계란 잡기/들기/던지기, 깨짐 물리, 닭 어그로 1종, 트럭까지 복귀.
재사용: 3D 음파 프로토의 평면 충돌과 "로직은 평면·렌더는 3D" 구조. 1인칭 컨트롤은 시점이 1인칭으로 결정될 경우에만. ← Round 2

**2차 — Unity 또는 Unreal (구매 에셋 활용)**
웹 프로토가 "오"를 통과한 뒤에만 진입. 넷코드 계획은 엔진 선택과 묶어서 미결.

## 정전 귀환 스테이지 — 음파 자산의 착지점 (2026-08-10 확정)

핵심 결정 7("음파 자산은 재활용")의 구체안. **양계장 본편이 아니라 별도 스테이지다.**
본편은 시야 기반으로 이미 지어져 있고(실내 240/실외 160, 케이지 열 LOS, "밝은 곳=위험"
어포던스, 계란 발광, 빛 웅덩이 동선), 거기에 어둠+음파를 넣으면 그 전부가 무의미해진다.

### 인과
계란을 훔쳐 나온 **귀환 길에 정전.** 어둠 속을 트럭까지 돌아간다.
밤 농장에 불 나가는 데 설명이 필요 없다 — 왜-질문이 공짜인 설정(핵심 결정 3)을 유지한다.

### 시작과 끝 (2026-08-10 개발자 확정)
- **시작: 마지막 필요분 계란을 집는 순간** (반납 2개 상태에서 3개째 픽업). 판당 정확히 1회,
  "다 훔쳤다 → 들켰다 → 불 나갔다"로 인과가 공짜고, 가장 깊은 나르기가 자동으로 클라이맥스가 된다.
  별도 판이 아니라 **본편 판의 후반부**로 붙는다 (기술 로드맵의 후보 중 확정).
- **끝: 반납대 도달.** 정전 구간 = 어둠 속 한 번의 나르기.
- 구조가 주는 공짜 이득: **들어갈 때는 불이 켜져 있다.** 진입은 경로 학습(정찰 투자)이고,
  귀환은 그 기억을 어둠 속에서 파동으로 재구성하는 시험이다. 같은 맵이 두 번 다르게 쓰인다.
- 프로토 v0.3 실측 근거: 깊은 둥지→축사 문 3,641 / 문→반납대 520. 귀환의 87%가 축사 안이므로
  정전 무대는 축사 내부다 — 새 맵이 필수는 아니다.

### 맵 요구 — 더 크고, 미로 같아야 한다 (2026-08-10 개발자 확정)
종료가 "반납대 도달"인 이상, 어둠 구간은 나르기 한 번뿐이다. 현재 축사(정연한 5열 격자)에서는
서쪽으로 직진하면 끝이라 시험이 성립하지 않는다 — **길을 잃을 수 있어야 스테이지가 성립한다.**
단, 미로는 본편의 무음 3초 판독·빛 사슬 동선과 정면으로 긴장한다. 미로가 "어디에 사는가"는 미결:
- (a) 공유 맵 자체를 미로화 — 본편도 미로가 된다. 가독 보정(빛 사슬 강화·바닥 표시) 필수
- (b) **정전 순간 보안 셔터가 내려와 경로가 바뀐다** — 맵은 본편 그대로, 어둠에서만 미로.
  들어온 길이 그대로는 안 나가지므로 학습한 경로가 무효화되고 파동 재탐색이 강제된다.
  인과도 공짜(정전=셔터). 구현은 게이트 세그 토글 수준
- (c) 정전 전용 별도 맵 — 문서의 원래 그림에 충실하나 비용 최대

(2026-08-10 개발자) **지금 맵은 미로화 없이 확대만 한다.** b안(셔터)은 나중에 새 레벨 만들 때
고려. 여기 적힌 아이디어들은 지금 맵에 안 쓰여도 다른 맵에서 쓸 수 있다 — 지우지 말고 남겨둘 것.
왕복 시간 상한도 제약이 아니다(45초 초과 허용).

### 승계하는 긴장
v1 "소리는 빛이다"의 딜레마 그대로: **보려면 소리를 내야 하는데, 소리를 내면 들킨다.**
v1에서 이 딜레마를 푸는 도구는 던지는 돌이었다. 여기서는 **계란**이 그 자리에 온다 —
그리고 돌과 달리 계란은 유한하고 깨지고 목표물이다. 같은 구조가 훨씬 비싸진다.

### 동사는 그대로 (핵심 결정 4 유지)
새 조작을 추가하지 않는다. **던지기 하나가 세 갈래로 갈린다:**
길이 보인다(파동) / 닭이 그쪽으로 쏠린다(미끼 — 프로토 v0.3에 이미 있음) / 계란 하나를 잃는다.
플레이어가 매번 "이걸 조명으로 쓸까 납품할까"를 저울질하게 되고, 그 판단이 곧 게임이다.

### 클립 가독 대응 — 이 스테이지 최대 리스크
검은 화면은 "무음 3초 판독" 필터를 정면으로 위협한다. v1이 실제로 이 문제를 안고 있었고,
아직 친구 반응이 없어 검증되지 않았다.
대응: **들고 있는 계란이 곧 조명이자 판독 앵커다.** (프로토 v0.3에서 계란은 이미 상시 발광)
검은 화면에 하얀 계란 하나가 뒤뚱거리며 가고 뒤에서 점들이 몰려오는 그림 —
소리를 꺼도 "뭔가 훔쳐서 도망친다"가 읽힌다. 이 그림이 안 나오면 스테이지를 접는다.

### 신규 시스템 회계
이 스테이지의 신규 시스템 **1개 = 파동 시각화(음파 렌더)**.
나머지는 전부 재사용이다: 맵 선분·원-선분 충돌·도트 풀·셰이더는 두 프로토가 이미 공유하고,
미끼/강탈/흔들림/깨짐은 v0.3 그대로 쓴다.
기술 부채 한 가지: v1의 차폐는 "모든 지오메트리를 새까만 depth-writer로 두는" 트릭이라
v0.3의 색 있는 재질·점광원과 충돌한다. 정전 시 재질 스왑이 필요하다(v1 디버그 모드가 이미 하는 일).

### 검증 질문
"어둠 속에서 계란을 들고 돌아오는 것이 조작만으로 긴장되는가."
본편의 검증 질문("잡고 나르기+깨짐+동물 반응이 웃긴가")과 **별개로** 수집한다.

### 착수 조건
본편 프로토의 친구 반응을 받은 뒤. 데이터 0인 상태에서 코어 메카닉을 둘로 늘리면
결과가 나빴을 때 어느 쪽이 원인인지 귀속할 수 없다 (전제 8: 검증은 프로토 먼저).

## 미해결 질문

- 이름 (가제도 미정)
- 이동 기지의 스킨: 푸드트럭 vs 캠핑카 vs 우주선 — "장사한다"는 프레임(주문·납품 인과)은 확정, 겉모습과 배경 세계는 미정. 스킨 선택이 동물·재료 목록(지구 농장 vs 외계 생물)까지 결정하므로 생각보다 큰 갈림길
- 시점: 1인칭 vs 3인칭 — "몸이 보임" 필터와 물리 코미디는 3인칭이 유리할 수 있으나, 협동에선 1인칭도 남의 몸은 보임(리썰·REPO 선례). 웹 프로토에서 A/B 가능

## 어떻게 생각하는지에 대해 본 것

- "가운데 종을 치고온다해. 왜치고와야될까" — 규칙보다 인과를 먼저 묻는다. 이 질문이 종 안을 죽였고, 그 덕에 설정이 공짜인 프레임까지 왔다.
- "물건을 가지고 나오자, 이런내용이아니야 … 핵심적인 게임요소가 있었으면해" — 경제 구조와 동사를 구분해서 듣는다. 이 구분이 이 세션의 방향타였다.
- "프라이팬은 2계란 이런식" — 예시 하나로 경제 전체(교환 사다리, 깨짐 물리, 무기 겸용)를 함축했다.
