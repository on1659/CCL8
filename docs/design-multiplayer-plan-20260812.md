# 멀티플레이 4인 계획 — 웹 프로토 기준 (2026-08-12)

> 상태: **계획 문서만. 구현 금지 유지.** 개발자가 이 문서를 확인·승인하면 별도 라운드에서 구현한다.

## 0. 목표 형태

1~4인 협동. 한 명이 방을 만들고 링크(방 코드)를 공유하면 친구가 브라우저로 입장.
훔치기·운반·정전 귀환을 같이 한다. 경쟁 요소 없음 (팀 공동 수확).

## 1. 방식 결정

### 채택 권장: WebSocket 릴레이 + 호스트 권위

- 구성: 소형 Node 서버(ws, ~100줄) — 방 코드(4자) 발급·중계만. 게임 시뮬레이션은 **호스트 브라우저**가 단독 실행.
- 클라이언트 → 호스트: 입력 인텐트만 (이동 벡터, 버튼 이벤트). 호스트 → 전원: 월드 스냅샷 20Hz(~1KB: 플레이어 4 + 닭 10 + 알 6 + 수레) + 원샷 이벤트 채널(파동·사운드·bigmsg — 스냅샷에 못 싣는 순간 신호).
- 클라이언트는 스냅샷 보간 렌더 + 자기 입력 즉시 반영(로컬 예측은 이동만, 규칙 판정은 전부 호스트).
- 이유: 프로토 단계에서 가장 싸고, 치팅 걱정 없는 신뢰 모델(친구 협동), 서버는 상태 없는 파이프라 무료 티어로 충분.

### 반려 1: 결정론 락스텝 (전원이 입력만 교환, 각자 시뮬)

- **반려 사유 (재론 봉쇄용 기록)**: 이 게임의 "결정론"은 조우 결정론(리터럴이 조우를 결정)이지 시뮬 결정론이 아니다 — `pickWander`·순찰 dwell 지터가 `Math.random`을 쓰고 닭 위치에 실효한다. 락스텝화하려면 시드 RNG 전면 교체 + 부동소수 프레임 일치 보장이 필요하고, 4인 웹에서 입력 지연 결합(제일 느린 사람이 전원을 끌고 감)도 나쁘다.

### 반려 2: WebRTC P2P

- 서버가 없다는 장점이 있으나 시그널링 서버는 어차피 필요하고, NAT 실패 케이스 대응(TURN)이 프로토 가치 대비 비싸다. WebSocket 릴레이가 같은 예산으로 항상 된다.

## 3. 현재 코드의 "단수 전제" 목록 (M1에서 해체할 것 — 코드 실측)

- 전역 `player`, `held`, `pocket`, `charge`, `yaw/pitch`, `camMode`, `player.glove/stam/exhausted/swapT/jy`
- `LANTERN` 싱글턴 — "발광 알 운반자는 1명" 전제. 멀티에선 운반자별 필요. **주의: three.js는 라이트 수가 변하면 셰이더 재컴파일 히치** — 4개를 미리 씬에 상주시키는 현 패턴을 유지한 채 개수만 늘릴 것.
- `cart.pulled` — 누가 끄는지 신원 없음 → `cart.owner`
- 입력이 DOM 이벤트에서 직접 월드를 변이 (`tryPickOrPlace` 등 키다운 즉시 호출) — **이미 금지선 위반 중임을 정직 기록**. M1에서 인텐트 큐(프레임 시작 시 일괄 처리)로 전환해야 호스트가 원격 입력과 로컬 입력을 같은 경로로 처리한다.
- HUD·프롬프트·시야 원·게이지 바·닭 눈(EYE_MAT) — 로컬 뷰어 UI로 분류 (스냅샷 비대상, 각자 렌더)
- v0.9 신설분: `c.det` 충전은 "알 소지 플레이어 중 최대 요율 1인" 기준으로 재정의, 만충 시 그 플레이어를 표적. `carriesEgg()`/`EYE_MAT`는 "아무나 알을 들면"으로 재정의. 시야 원 반경(실내/실외)은 뷰어 위치 기준.

## 4. 이번 라운드(v0.9)가 지키는 무후회 금지선 5

1. 신규 AI 코드는 플레이어 좌표를 `targetOf(c)` 액세서로만 읽는다 (지금은 항상 `player`를 반환 — 3줄 공짜).
2. `zoneOf`/`groundY`는 순수 함수 — 엔티티에 층 필드를 저장하지 않는다 (스냅샷에 층을 실을 필요가 없어짐).
3. "the player" 전제의 **새 전역을 추가하지 않는다** (기존 것은 M1에서 일괄 해체).
4. 월드 변이는 update(dt) 경유 유지, 원샷 연출(파동·버스트·사운드)은 호출 지점이 명확한 함수 경유 유지 (이벤트 채널로 승격하기 쉬운 형태).
5. 조우 결정론 유지 (outcome RNG 금지) — 호스트 권위라 시뮬 결정론은 불요하지만, 조우 결정론은 협동 학습("2번 통로는 30초 주기")의 기반이라 계속 지킨다.

## 5. 협동 설계 질문 (M4에서 확정 — 지금 정하지 않는다)

- 정전 트리거의 "확보 총량"은 팀 합산인가 (권장: 예 — 4인이 3개를 나눠 들면 그 순간 암전)
